How scoring works
1. Match points
Every player on the winning pair earns 3 tournament points. Every player on the losing pair earns 1 tournament point. The score margin does not change these points.
2. First tie-break: capped point difference
For each match, calculate each player's team's score minus the opposing team's score. Cap that match's contribution at +5 / −5 for 21-point games, or +3 / −3 for 15-point games. Add these capped differences across all matches played by that player.
3. Ranking
Rank by tournament points first. If players are tied, the higher cumulative capped point difference ranks higher. If still tied, they share the position.
4. Why cap the margin?
A heavy defeat can only hurt the tie-break by a maximum of 5 or 3 points in that match. One bad game therefore cannot overwhelm the rest of the tournament.
5. Equal participation
4 players: 3 games each (3 matches). 5 players: 4 games each (5 matches). 6 players: 4 games each (6 matches).
Scores are entered as the final set score. For this tool, a match is recorded when one side reaches the selected target (15 or 21).

Scoring rules
Win = 3 points
Each member of the winning pair receives 3 tournament points.
Loss = 1 point
Each member of the losing pair receives 1 tournament point, regardless of how large the defeat was.
Tie-break = capped point difference
Calculate score-for minus score-against for each match. Cap each match's contribution at ±5 for a 21-point game and ±3 for a 15-point game. Add the capped differences across all games played.
Final ranking
1) Total tournament points. 2) Cumulative capped point difference. If still tied, players share the position.
